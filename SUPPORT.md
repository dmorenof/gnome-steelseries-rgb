# Support and project status

SteelSeries RGB Controller GNOME is an independent community application. It is unaffiliated with MSI and SteelSeries. Maintenance and issue responses are best effort, with no official support commitment or response-time guarantee.

The software is a pre-release. The README and compatibility matrix describe supported and experimental capabilities. Additional keyboards, hardware-state readback and native effects require further verification.

For a reproducible issue, include the application version, Linux distribution, desktop/session type, keyboard model/layout and the steps that produced the result. Report the displayed status separately from the observed keyboard state. Share sanitized excerpts rather than full device/input dumps.

Software defects can be investigated through the repository issue tracker after publication. For sensitive reports, follow [security reporting](SECURITY.md). [Known remaining work](docs/ROADMAP.md)
