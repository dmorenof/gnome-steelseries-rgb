# Changelog

## 0.2.0-alpha.12 — 2026-11-17

- Add a bounded offline native-effect inspector with structural checks and explicit timing hypotheses.
- Test zero-duration/count rejection, field consistency, hypothetical drift/clipping and 2,500 mutated inputs.
- Record rightward Rainbow Wave as the first target for physical animation support.
- Record the owner's conditional publication destination. Physical native effects remain pending target-specific evidence.

## 0.2.0-alpha.11 — 2026-11-17

- Preserve corrupt/future settings and reject stale writes from another process.
- Validate JSON boundaries and serialize profile/map-record updates.
- Reject duplicate RGB address selections and require the known full GT76 control descriptor.
- Retain failed USB changes for retry and distinguish subsequent persistence errors.
- Complete bounded OpenRGB close/queue handling and include LED/matrix/mode signatures in checks.
- Remember a positive RGB intensity for recovery after reopening an off configuration.
- Separate shared color, persistence, distribution and desktop-integration responsibilities.
- Stage runtime updates with rollback on swap failure and validate desktop paths.
- Add regression/GTK/installation checks, deterministic source archives and CI definitions.
- Rewrite public documentation in English and record remaining hardware release gates.

## 0.2.0-alpha.10 — 2026-11-10

Added GT76 profile rename and JSON import/export, with duplicate-name protection and GTK/storage roundtrip checks.

## 0.2.0-alpha.9 — 2026-11-10

Added immediate multi-selection editing to the experimental OpenRGB window, merging unselected server colors and rejecting mode changes.
